Problem statement & Goal

We spend far too much time filtering the flood of information down to what’s actually relevant to us. The goal of this project was to build an autonomous system that aggregates a large number of RSS feeds, evaluates the content against predefined criteria, and structures the most important findings.
  • → No more ongoing manual review of sources.
  • → Only relevant information instead of information overload.
  • → More signal, less noise.
Objective

“Reducing daily research time while increasing the depth of information through LLM-supported analysis. Focus on the most relevant articles instead of manually reviewing large amounts of information.”

Approach & Workflow

Implementation of a fully automated, modular news pipeline. The Python-based solution was built with Claude Code following various security best practices, so that sensitive data, credentials, personal preferences and so on are never published. The script can be connected to any LLM API. I used Gemini as the base and Groq as a fallback, both on their free tiers.

Key Learnings

01
Architecture

Splitting monolithic code into modules early on pays off once changes come later.

02
Git

Clean branching even on small projects saves a lot of trouble.

03
Mock Mode

Even the most generous free tier runs out quickly during testing, so it’s worth working with a mock mode from the start.

04
Security

A security audit by a second LLM at the end turned out to be surprisingly valuable and surfaced real findings.

05
Value

Less is more: v4 without summaries is faster, cheaper, and in most cases just as useful as v3 with summaries.

Enhancement Ideas & Considerations

01
Keyword watchlist

Certain terms (company name, technology, person) automatically boost the score. Useful when you want to closely follow specific topics.

02
Blacklist

Set up a hard filter for certain topics through a blacklist.

03
Newsletter integration

Add newsletters as a data source alongside RSS feeds (e.g. via Kill-the-Newsletter).

04
Personalized scoring

Instead of one global interest profile, different weightings could be set per feed.

05
Feedback loop

Simple like/dislike buttons per article in the email, storing a score in a local file. Over time the system learns your own preferences.

06
Other output channels

Telegram, WhatsApp, Slack, Teams and similar, instead of sending by email.

07
Local AI

LLM APIs could be replaced with a local AI.
