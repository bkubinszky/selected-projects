Implementation & Workflow

Implementation of a fully automated, modular news pipeline. The Python-based solution was built with Claude Code following various security best practices, so that sensitive data, credentials, personal preferences and so on are never published. The script can be connected to any LLM API. I used Gemini as the base and Groq as a fallback, both on their free tiers.
