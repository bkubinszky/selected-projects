Privacy Policy

Controller

The controller responsible for data processing on this website is:

Balázs Kubinszky

Hosting

This website is hosted through GitHub Pages, a service provided by GitHub Inc. (a subsidiary of Microsoft Corporation) based in the United States. When you visit this website, technical access data (including IP address, date and time of access, page requested and browser used) is automatically recorded by the hosting provider in server log files. This data is not accessible to the operator of this website and is processed exclusively by GitHub to ensure reliable operation and to protect its systems.

More information on data processing by GitHub can be found in GitHub’s privacy statement: https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

External resources (icon library)

This website loads the Ionicons library through the unpkg.com content delivery network (CDN) to display icons. When this resource is loaded, the IP address of the visiting device is transmitted to the operator of this CDN. This data is not combined with any other personal data.

Local browser storage

This website stores a single setting (the choice between light and dark display mode) locally in the visitor’s browser, known as local storage. This information never leaves the visitor’s device, is never sent to the server, and is used solely to remember the display preference during a visit. No cookies are set and no tracking technologies are used.

No collection of personal data by the website operator

This website does not use any analytics or tracking services (such as Google Analytics), displays no advertising, and contains no contact or other forms through which visitors could submit data. The operator of this website therefore does not actively collect any personal data.

Contacting us

If you get in touch by email or through one of the linked profiles (GitHub, LinkedIn), the data you provide (such as your name, email address and message content) will only be used to handle your inquiry and will not be shared with third parties.

Your rights

For any privacy-related questions, feel free to reach out at the email address above at any time.
